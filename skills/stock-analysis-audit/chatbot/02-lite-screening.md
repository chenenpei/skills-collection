# 02 Lite Screening Prompt

用于传统 Chatbot 的默认初筛。适合在只想快速判断“是否值得继续研究”时使用。

## Prompt

请对以下公司进行 Lite 初筛：

- 公司 / Ticker：`[填写公司名或 Ticker]`
- 已确认上市地：`[可选]`
- 用户能力圈说明：`[可选；如果没有，请在能力圈部分标记为信息不足]`

如果你没有联网能力，或无法可靠获得实时数据，请不要编造数据。请说明需要我补充哪些最小数据，或基于我已提供的数据做有限分析。

## Lite 初筛任务

请按以下顺序输出：

1. 一句话结论
2. 公司识别结果
3. 数据质量与缺失项
4. 商业模式判断
5. 关键财务摘要
6. 当前估值与指数机会成本
7. 最大三个风险
8. 初步裁决
9. 需要进一步验证的数据

## 关键要求

- 不要生成 5-10 年完整表格，除非我提供了数据。
- 所有数字必须标注日期、口径和来源。
- 查不到的数据写 `N/A`。
- 如果数据质量为 Low，裁决不得高于“观察名单”。
- 如果公司身份存在歧义，停止并让我选择，不要继续分析。
