# 01 Company Identification Prompt

用于传统 Chatbot 的第一步：识别用户想分析的上市公司。

## Prompt

请根据我提供的关键词识别上市公司。关键词如下：

`[在这里填入公司名、Ticker、简称或业务关键词]`

请先完成公司识别，不要直接进入财务分析。

## 识别任务

请输出：

1. 最可能的公司全名
2. Ticker
3. 主要上市地
4. 主要交易货币
5. 主营业务一句话说明
6. 是否存在 ADR、双重上市、A/H 股、不同 share class 或同名公司
7. 识别置信度：High / Medium / Low

## 停止条件

如果存在多个可能对象，请不要继续分析。请列出候选项，并让我选择。

如果证券代码、上市地或公司身份无法可靠确认，请只提出一个最关键的问题，不要生成财务分析。

## 输出格式

```markdown
## 公司识别结果

- 识别对象：
- Ticker：
- 主要上市地：
- 交易货币：
- 主营业务：
- 潜在歧义：
- 识别置信度：

## 下一步

如果识别置信度为 High，请说明可以进入 Lite 初筛。
如果识别置信度不是 High，请说明需要我确认的最小信息。
```
# User Prompt：公司识别

**使用时机：** 新对话第一轮，或用户只给出公司名/简称/Ticker 时。  
**前置：** 已设置 `00-system-prompt.md` 为 System。

---

## 任务

根据用户提供的公司关键词，完成公司识别。**不要**在本阶段输出完整财务分析或投资建议。

用户关键词：`{{在此粘贴：公司名 / Ticker / 简称 / 业务描述}}`

## 你必须完成

1. 列出最可能的 1-3 个上市公司候选（公司全名、Ticker、主要上市地、主要货币、主营业务）。
2. 说明是否存在 ADR、A/H 股、双重上市、不同 share class 或同名公司风险。
3. 若只有一个高度确定的候选，在开头写明：  
   `我将本次分析对象识别为：公司名 / Ticker / 主要上市地。`
4. 若存在多个合理候选，**停止分析**，一次只问用户一个问题，并给出候选项让其选择。
5. 若无法可靠确认，说明原因，并列出需要用户确认的最小信息。

## 输出格式

1. 识别结论（确定 / 多候选 / 无法确认）
2. 候选列表（表格）
3. 歧义与风险说明
4. 下一步建议（进入 Lite 初筛 / 等待用户确认 / 请用户补充 Ticker）

## 禁止

- 在无确认标的的情况下编造财报或估值数据。
- 一次提出多个追问（一次只问一个问题）。
