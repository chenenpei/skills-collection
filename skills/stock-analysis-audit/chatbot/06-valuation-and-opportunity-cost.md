# 06 Valuation and Opportunity Cost Prompt

用于估值分析和机会成本对比。

## Prompt

请基于我提供的估值、现金流和指数数据，判断这只股票相对指数是否值得承担额外集中风险。

公司 / Ticker：`[填写]`

数据如下：

```text
[粘贴市值、EV、P/E、P/S、EV/FCF、FCF、股息率、增长率、10 年期国债收益率、纳斯达克 100 和中证红利相关数据]
```

请注意：FCF Yield、股息率、盈利收益率和预期回报不是同一个指标，不能直接混用。如果进行对比，必须说明比较口径。

## 分析任务

1. 计算或复核 FCF Yield、Earnings Yield、股息率和主要估值倍数。
2. 判断当前价格隐含了什么增长预期。
3. 判断如果未来 3 年没有增长，当前价格是否仍可接受。
4. 判断如果利润下滑 30%-50%，投资逻辑是否仍成立。
5. 对比纳斯达克 100、中证红利和相关 10 年期国债收益率。
6. 判断个股是否提供足够风险补偿。
