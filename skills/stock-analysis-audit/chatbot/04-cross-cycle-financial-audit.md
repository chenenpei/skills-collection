# 04 Cross-Cycle Financial Audit Prompt

用于在用户已经提供 5-10 年财务数据后，进行跨周期财务审计。

## Prompt

请基于我提供的历史财务数据，对公司进行跨周期财务审计。

公司 / Ticker：`[填写]`

数据如下：

```text
[粘贴 5-10 年财务数据，至少包括收入、净利润、经营现金流、Capex、FCF、ROE/ROIC、股数、净债务或净现金]
```

请不要使用未提供且无法验证的数据。如果某项数据缺失，请写 `N/A`，并说明该缺失会影响哪些判断。

## 审计任务

1. 整理 5-10 年财务表。
2. 判断收入增长是否稳定，还是依赖周期、并购、价格上涨或一次性因素。
3. 判断利润率是否存在结构性改善或恶化。
4. 对比累计经营现金流与累计净利润，检查利润含金量。
5. 判断 FCF 是否真实可持续，还是来自压缩投资、延迟付款、裁员或一次性因素。
6. 判断 ROE/ROIC 是否来自经营优势，还是来自杠杆、回购、低权益基数或周期顶部。
7. 检查股数稀释、债务、利息费用和到期结构风险。
