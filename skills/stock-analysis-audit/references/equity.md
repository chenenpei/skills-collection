# 股票定性研究框架

本文件适用于所有单一普通股研究。它回答的是“市场可能错在哪里，以及这种差异能否传到普通股并在期限内被重新定价”，不是把低估值自动解释为机会。先读 [CONTEXT.md](../CONTEXT.md) 的模式和结论定义，再按公司行业加载 [data.md](data.md) 与适用的行业分支。轻量审计只使用“研究对象和回报来源”“市场隐含命题卡”“证据、反证与未知”和“行业路由”；其余章节仅在深度审计或用户明确要求时加载。

## 先写清楚研究对象和回报来源

确认上市证券、股份类别、交易币种、报表主体和估值时点。用一句话说明回报来自哪一种或哪几种机制：持续经营和长期复利、成长再投资、周期恢复、资产折价、预期差，或中期估值修复。回报机制不是评级；如果无法说明普通股股东最终得到什么，先停在轻量审计或“无法可靠定价”。

把三个问题分开：

1. **价值问题**：在明确的经营、资本和风险要求回报假设下，当前价是否有风险补偿。
2. **预期差问题**：市场隐含的长期悲观结果是否比公开证据支持的结果更差。
3. **路径问题**：若存在预期差，什么新信息会在持有期限内让市场改变估值。

只有价值、预期差和路径同时达到最低要求，才可写“等待估值修复”。缺少路径时可以有长期观察价值，但不能把时间当作催化剂。

## 市场隐含命题卡

不要从“公司便宜”开始。先把价格转换成三至五个可争论的市场命题，并标明这是反推而不是市场共识的直接观测。

| 项目 | 必须写清的内容 |
| --- | --- |
| 市场命题 | 价格可能隐含的长期增长、利润率、资本回报、损失、稀释或分配结果 |
| 机制 | 哪条业务链会导致该结果：客户、定价、成本、竞争、监管、资本或现金 |
| 要求回报 | 该解释需要多高的风险补偿；与盈利假设分开，不把固定折现率当作市场事实 |
| 时间尺度 | 一季、一个经营周期，还是永久性变化 |
| 等待期 | 市场即使认可价值，为什么可能要等多个报告周期才重估 |
| 公开程度 | 已被广泛披露、只有间接线索，或主要不可见 |
| 可证伪事实 | 哪个公开事实会显著降低命题可信度 |
| 错误代价 | 若命题成立，普通股价值和研究判断会怎样受损 |

价格不能唯一识别预期。历史估值、同行倍数和新闻叙事只能提供线索；要用经营事实、资本约束、风险要求回报和可分配现金缩小解释范围。不要任选一个较低折现率，再把算术结果称作市场错误。

反推公式只用于产生假设范围。若用 `PB=(ROE−g)/(r−g)` 或类似关系，必须展示 `r`、`g`、ROE 的敏感性带，并把它们标为研究者假设；不能用 9.38% 或 10.29% 这类小数反推值声称知道市场真实预期。

## 业务机制到普通股的桥

把看多或看空叙事画成因果链：

```text
客户与交易条件 → 收入或利差 → 成本、风险和竞争 → 资本与再投资
→ 归属普通股东的利润／现金／每股权益 → 市场估值与可见催化剂
```

每个关键结论都要回答“谁承担风险、谁拿走增量、需要多少资本、普通股如何得到”。集团、少数股东、优先工具、债务、股权激励和监管留存不能被合并口径隐藏。利润改善若不能转成每股价值或可分配现金，不进入积极估值假设。

按公司类型从 [data.md](data.md) 选择经营指标。不要把全行业指标表当作必填清单；只收集能区分市场命题与替代解释的指标。

## 证据、反证与未知

把每条证据标成事实、计算、推断、判断或未知，并说明它支持哪条命题。用三层证据处理“没有恶化”：

| 证据层级 | 作用 | 处理 |
| --- | --- | --- |
| 公开可验证 | 已发生的报表、公告、交易、资本、分部和监管数字 | 记录主体、期间、口径与来源，可作为事实 |
| 部分可验证 | 正常化利润、客户质量、竞争优势、资产回收、战略结果 | 写出推断链，使用区间、压力情景和交叉证据 |
| 公开难以验证 | 内部风险容忍度、尾部模型、市场重估时点、未披露行为 | 若决定价值，降低确信或放弃该论点；若非决定性，用更高要求回报、较小暴露和时间限制处理 |

“没有恶化”只有在坏解释本应在该期间和该指标上留下可见痕迹时才有明显证明力。连续季度不是独立试验；同一底层过程产生的多个指标不能重复计入证据。若风险尚未经过暴露期、披露不覆盖关键部分，或结果可由核销、分母扩大和会计调整产生，应标为“未证伪”，不写成“市场错了”。

每项未知都写出三件事：能否由下一份披露降低、能否由压力测试约束、若仍未知会改变哪个行动或价格锚。无法约束且决定价值的未知，是停止定价或放弃研究的理由。

## 管理层与资本配置

管理层叙事只作为待验证假设。建立“承诺—资源—结果—股东传导”台账：

| 承诺或目标 | 截止日期 | 实际投入与资本 | 领先指标与最终结果 | 每股普通股是否受益 | 偏差及解释 |
| --- | --- | --- | --- | --- | --- |

至少回看一个完整周期，记录并购、扩表、再融资、分红、回购、资产处置、股权激励和风险偏好变化。检查改善有多少来自管理层决策、有多少只是行业共同周期；是否用规模、客户数或调整后利润替代每股回报；是否在压力期保护普通股而不是把风险推给新股东。只有资源配置和结果共同支持的战略，才可进入估值模型。

## 竞争、利润池和反向解释

任何正面解释都要提出一个最强负面替代解释：增量是否被价格竞争、渠道、供应商、监管、资本占用、技术替代或客户迁移拿走。任何“价值陷阱”结论也要先检查隐藏上行，避免只把便宜当作负面证据。

深度审计最多保留三项真正可能改变判断的隐藏上行，并为每项列出：可观察事实、普通股传导、最早验证时间、最强反证和当前状态（事实已出现／方向可解释／仍是猜想）。

## 时间、催化剂和价格锚

价值正确与价格及时修复是两件事。单独列出：

- 下一份财报或其他披露能验证什么，以及不能验证什么；
- 哪个经营变化、资本行动、监管确认或行业事件会改变市场长期假设；
- 谁会根据新信息更新预期（例如边际买方、监管者、债权人或公司资本行动），该事件在持有期限内为何可能发生，市场是否已经知道；
- 若没有新信息，为什么折价会收窄；
- 经过预先约定的报告周期仍无领先改善或催化剂时，是否时间停止。

价格锚使用 [CONTEXT.md 的价格分层](../CONTEXT.md#价格分层)。五个档位不是必须凑齐的数字：每个可用档位都要写价值依据、风险补偿、用途和撤销条件；“跑路价”写论点失效条件，不用固定跌幅代替。修复到合理价值区间时复核剩余回报和机会成本，不默认等待高估值。

价格锚必须给出输入的误差范围和适用状态。不要把四舍五入的账面价值、内含价值或情景价值计算到两位小数后当成精确交易门槛；优先使用宽区间、相对状态或“暂无法确定”。保险内含价值、集团 EV 和情景价格只有在资本、现金和普通股分配传导足够闭合时，才可作为可执行价值；否则只能作为诊断敏感性。

财报发布日期、定期审核日和价格触发是**信息节点**，不自动是催化剂。只有能改变外部投资者对长期利润、风险要求回报或普通股分配的事件才可写成重估催化剂。中期修复论点至少设置 2—4 个报告周期的时间停止；无领先指标改善或真实重估事件时，停止追加并重新估值。

## 研究处置门槛

| 处置 | 最低条件 |
| --- | --- |
| 现价有一点吸引力，可小仓观察 | 价格有风险补偿，坏状态可描述，关键资料没有致命冲突；尚未证明市场错误 |
| 有足够证据等待修复 | 至少一条领先证据链削弱悲观命题，能传到普通股，有期限内催化剂，延迟修复时仍不劣于替代资产 |
| 市场可能是对的 | 悲观机制完整，改善只是稳定或愿景，风险长期无法分散或分配，或没有时间优势 |
| 放弃研究 | 决定价值的未知无法约束，没有催化剂且研究成本超过可能优势，或连普通股传导链都无法解释 |

## 行业路由

- 银行、保险、券商、资管和综合金融：加载 [financial.md](financial.md)，再读 `data.md` 的金融部分；监管资本是约束，不是价值本身。
- 周期、制造和资源：重点验证供需、产能、库存、价格、成本、中周期盈利和资产负债表承压能力。
- 消费、服务和平台：重点验证留存、复购、量价、渠道库存、单位经济、获客成本、竞争反应和现金转化。
- 软件、半导体和高研发公司：重点验证研发产出、客户集中、技术替代、算力或供应链依赖、股权激励、稀释和达到自我融资的路径。
- 医药与生物科技：重点验证支付、集采、专利、管线、临床与监管、现金跑道和稀释；未盈利公司不能套用成熟企业现金流倍数。
- 其他行业：先画业务机制和利润池，再从 `data.md` 选能区分命题的经营指标；没有合适原型时保留“未分类”并解释原因。

## 最小深度报告骨架

深度报告沿用 [company.md](company.md) 的报告模板，但至少增加或明确以下内容：市场隐含命题卡、业务机制到普通股桥、管理层承诺台账、领先／确认／股东结果指标、催化剂和时间停止、可验证性分类、最强替代解释。只补能改变行动或价格的内容；不为满足章节数量填空。

## 同一事实包的流程验证

当用户要求比较旧报告和新方法时，先固定事实截止日和冻结价，保存旧报告为只读输入。先写旧报告差距审计，再在不读取旧结论和旧价格锚的前提下重做新报告，最后按预先登记的标准交叉审计。新报告引用旧结论、只增加章节而不增加可证伪性，或使用更精细的数字掩盖未知，均不算方法改进。只有交叉审计证明有效的规则才回写 skill。
