# stock-analysis-audit

证据优先的证券分析审计技能，覆盖单一公司股票、ETF、指数基金、主动基金和其他集合投资工具。

个股审计判断公司是否值得继续投入研究，以及证券在什么条件下相对指数和低风险资产有吸引力。基金审计判断基金是否是实现目标暴露的合适工具。所有结论仅用于研究辅助。

## 模式

正式模式只有“轻量审计”和“深度审计”。

| 用户表达 | 识别为 |
| --- | --- |
| Lite、快速审计、轻度审计、初步研究 | 轻量审计 |
| Deep、深度研究、全面审计、完整分析 | 深度审计 |

新任务没有指定模式时默认轻量审计；继续已有任务时沿用当前模式。轻量审计建议深入研究不会自动升级。“深度审计，尽量快一点”仍执行深度审计，只在取证与表达上提高效率。

个股轻量审计给出“继续研究、等待条件、不再继续、无法判断”之一。“未审”是独立的执行状态，不是负面结论。个股深度审计形成完整论证、条件式行动和有依据的价格锚；证据不足时可以正常结束为“无法可靠定价”，不套统一评级阶梯。

深度报告默认使用“市场价（合理价值参考）／打折价／捡漏价／恐慌价／跑路价（论点失效条件）”解释价格与论点，当前交易价单列。各档依据公司自身价值与风险推导，资料不足可暂无法确定；恐慌低价先复核，跑路条件不等同于固定止损价，高估后的持有／减持复核另述。具体定义见 [价格分层](CONTEXT.md#价格分层)。

基金提供五类结论：不采用、观察、卫星配置、核心配置、仅限战术配置。基金作为工具审计，不使用个股财务与商业分类。缺少个人背景不阻止基金研究；核心配置结论只说明适用前提，不断言用户理解或适合。

## 安装与 Agent 用法

在目标项目目录安装：

```bash
npx skills add https://github.com/chenenpei/skills-collection --skill stock-analysis-audit -y
```

已克隆本仓库时：

```bash
npx skills add . --skill stock-analysis-audit -y
```

Agent 会按对象与模式加载相应参考文件，并使用实际可用的浏览、文件、数据与 subagent 能力。常用请求示例：

```text
用 stock-analysis-audit 对 Microsoft 做轻量审计，报告用中文。
```

```text
用 stock-analysis-audit 对 Adobe 做深度审计，重点检查 FCF 质量、SBC、AI 风险和估值。
```

```text
用 stock-analysis-audit 对这批 A 股做快速审计，逐项列明继续研究、等待条件、不再继续、无法判断或未审。
```

```text
用 stock-analysis-audit 对 SMH 做轻量基金审计，重点看组合增长归因和同类比较。
```

```text
用 stock-analysis-audit 深度比较 SOXX 和 SMH 作为半导体暴露工具。
```

## 通用 Chatbot 用法

[chatbot.md](chatbot.md) 已包含共同指令、可选身份确认和四种模式。使用时：

1. 把“共同指令”贴到 Chatbot 的 system prompt；没有 system prompt 入口时，先作为第一条消息发送。
2. 再贴“身份确认（可选）”或一个模式：个股轻量审计、个股深度审计、基金轻量审计、基金深度审计。
3. 在模式输入区填写证券和已有材料。

共同指令与一个所选模式就是完整组合，不需要先后运行多个冗余阶段提示词，也不依赖 Chatbot 能读取本仓库。身份已经清楚时跳过身份确认。无工具 Chatbot 只基于用户提供的材料；只有名称或代码时，它可以确认身份和规划研究问题，但不能虚构当前财报、持仓、估值或行情。有实际浏览、文件或数据能力时，按提示词使用这些能力。

## 报告与质量检查

报告默认使用中文标题、表头、评价词和正文；用户明确指定其他语言时整体切换。常用财务缩写可保留，但每份报告首次出现时解释中文含义。每次研究以一份报告为主要交付：个股轻量开头给研究处置，基金开头给结论摘要，个股深度开头给判断地图；正文展开证据与反证，结尾给边界和重审触发。机器可读字段只在用户要求或明确程序对接时按需输出，默认不附 slug 表。

个股报告应能回答：

- 证券身份、数据时点、币种、股份类别和关键口径是否清楚；
- 产品卖给谁、利润如何形成、关键依赖是什么；
- 盈利、现金、再投资、资本回报、资产负债表和行业适用指标说明了什么；
- 谁能破坏利润池，是否存在被遗漏的经营转折、资产或新利润来源；
- 深度审计是否完整展开护城河、管理层、估值、机会成本、对抗和证伪；
- 价格锚是否可复算、有价值依据与风险补偿，或为何无法可靠定价。

基金报告应能回答：

- 基金载体、组合暴露和底层持仓三层是否分开；
- 至少一个同类基金和一个宽基的比较是否支持结论；
- 前十大权重超过 50% 时，轻量审计是否补充前十大明细；深度审计是否在资料可得时覆盖前 10–20 大持仓；
- 行业或主题基金是否以组合而非单一龙头做增长归因；
- 组合市盈率是否来自同口径披露、组合总市值除以组合盈利，或盈利收益率加权后取倒数，而非成分市盈率的市值权重算术平均；
- 主动基金是否检查经理任期、主动份额、换手、费用税负和因子归因；
- 最终结论是否评价基金作为暴露工具及其组合角色。

所有关键数字都应保留主体、期间、币种、日期、来源和计算口径。低估值本身不是安全边际，好公司本身也不等于有吸引力的证券。单公司深度审计没有 subagent 时应披露“单模型分阶段对抗”，不声称独立；轻量审计只需最强支持、反证与处置。无可靠计时能力时按研究阶段检查进展，不伪称精确执行约 30 分钟的软检查点。
